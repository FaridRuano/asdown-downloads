Descarga videos MP4 y audio MP3 desde tu computadora o desde un panel de Adobe.

[Descargar Asdown para Windows](https://github.com/FaridRuano/asdown-downloads/releases/latest/download/Asdown-Setup-1.2.2-x64.exe)

## After Effects y Premiere Pro

[Descargar instalador de los plugins](https://github.com/FaridRuano/asdown-downloads/releases/latest/download/Asdown-Adobe-Setup-0.1.3-x64.exe)

Un instalador para ambas aplicaciones. Cierra Adobe antes de instalar. Después abre Ventana → Extensiones → Asdown y guarda tu proyecto antes de descargar.

Windows 10/11 x64. El panel está dirigido a Adobe 2025/2026; la compatibilidad puede variar por versión. Descarga únicamente contenido propio o con permiso.

Los archivos de desarrollo EXE no llevan firma Authenticode de editor verificado. El panel incluido lleva una firma ZXP local. Conserva los avisos de terceros incluidos; las sumas SHA-256 están en cada release.
